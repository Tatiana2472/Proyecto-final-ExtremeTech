# Fotografías propias

Coloque aquí una imagen con el **slug del producto** como nombre de archivo:

    monitor-lg-ultragear-24-165hz.jpg
    consola-playstation-5-slim.png

Extensiones aceptadas: `.jpg`, `.jpeg`, `.png`, `.webp`.

Estas fotos tienen prioridad sobre cualquier otra fuente. Se usan sobre todo
para **Monitores** y **Gaming**, categorías de las que DummyJSON no publica
fotografías.

Después de agregarlas, ejecute:

    php artisan catalogo:imagenes
